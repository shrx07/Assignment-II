# Assignment-II
This project is a personal portfolio website created using HTML, CSS, and JavaScript.
The website showcases personal information, skills, projects, and contact details in a clean and interactive way.

Project Description:
The purpose of this project is to design a responsive and user-friendly portfolio website that represents a developer’s profile. It demonstrates basic web development skills including structure, styling, and interactivity.

Technologies Used:
1) HTML- for creating the structure of the website
2) CSS- for styling and layout design
3) JavaScript- for adding interactive elements

Features:
1) Responsive portfolio layout
2) Navigation menu for different sections
3) About Me section
4) Skills section
5) Projects showcase
6) Contact section
7) Interactive elements using JavaScript

Objective: 
The objective of this assignment is to understand how HTML, CSS, and JavaScript work together to build a functional and visually appealing website.
